## 本地查看

双击 `index.html` 即可在 Windows 默认浏览器中打开。网站不依赖安装环境、外部字体或在线脚本。

## 文件结构

- `index.html`：网站页面及文字内容
- `assets/css/styles.css`、`assets/css/cases.css`：视觉、案例与响应式样式
- `assets/js/main.js`：移动导航、滚动展示、联系方式复制与案例大图预览
- `assets/images/`：经过网页压缩的品牌与业务图片

## 更新真实案例

案例图片位于 `assets/images/cases/`。新增案例时，在 `index.html` 中复制“落地案例”区域的 `<figure>` 卡片并替换图片路径、替代文字、分类及标题。请勿删除图片的 `loading="lazy"` 属性。
